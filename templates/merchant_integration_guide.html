আপনার Django website-এ Gateway যুক্ত করুন

এই নির্দেশনা আপনার developer-কে দিতে পারেন। প্রথমে API credentials ও payment number সেট করুন, তারপর backend থেকে checkout তৈরি এবং signed webhook যাচাই করুন।

API Credentials দেখুন Payment Number সেট করুন

Payment শুরু করার আগে

  1. Dashboard-এর Payment Accounts থেকে bKash/Nagad/Rocket number যোগ করে Active করুন।
  2. এই merchant-এর API Key এবং API Secret নিরাপদে server environment-এ রাখুন।
  3. Super Admin-কে আপনার আলাদা Webhook URL ও Return URL merchant settings-এ configure করতে বলুন।
  4. Payment matching চালাতে gateway-র SMS Forwarder/device configuration সম্পূর্ণ থাকতে হবে।

callback_url checkout request-এ পাঠাবেন না। Gateway-তে এটি webhook destination এবং customer return—দুই কাজেই ব্যবহৃত হয়। Merchant settings-এ আলাদা URL configure করান।

ধাপ ১ — Django project প্রস্তুত করুন

HTTP request পাঠাতে requests ইনস্টল করুন:

pip install requests

Project root-এ `.env` ফাইল বা hosting environment settings-এ credentials দিন:

GATEWAY_BASE_URL=https://payment.webkoders.com
GATEWAY_API_KEY=আপনার_API_KEY
GATEWAY_API_SECRET=আপনার_API_SECRET

`.env` GitHub-এ push করবেন না। API key/secret HTML বা JavaScript-এ রাখবেন না।

`settings.py`-এ environment থেকে পড়ুন (এখানে `python-decouple` ব্যবহার করা হয়েছে):

pip install python-decouple

# settings.py
from decouple import config

GATEWAY_BASE_URL = config(
    "GATEWAY_BASE_URL", default="https://payment.webkoders.com"
).rstrip("/")
GATEWAY_API_KEY = config("GATEWAY_API_KEY")
GATEWAY_API_SECRET = config("GATEWAY_API_SECRET")

ধাপ ২ — Checkout invoice তৈরি করুন

Browser থেকে amount নেবেন না; নিজের database-এর Order object থেকে নিন। উদাহরণে `Order` model-এর `amount`, `customer_name`, `customer_email`, `customer_phone` field আছে ধরে নেওয়া হয়েছে। নিজের field name অনুযায়ী বদলাবেন।

# payments/services.py
import requests
from django.conf import settings

class GatewayError(Exception):
    pass

def create_gateway_checkout(order):
    payload = {
        "order_id": str(order.pk),
        "amount": f"{order.amount:.2f}",
        "currency": "BDT",
        "customer_name": order.customer_name or "",
        "customer_email": order.customer_email or None,
        "customer_phone": order.customer_phone or "",
        "metadata": {"local_order_id": str(order.pk)},
    }
    try:
        response = requests.post(
            f"{settings.GATEWAY_BASE_URL}/api/v1/checkout/create/",
            headers={"X-API-KEY": settings.GATEWAY_API_KEY},
            json=payload,
            timeout=20,
        )
        response.raise_for_status()
        result = response.json()
    except (requests.RequestException, ValueError) as exc:
        raise GatewayError("Gateway checkout তৈরি করা যায়নি") from exc

    if result.get("status") != "success" or not result.get("checkout_url"):
        raise GatewayError("Gateway checkout link দেয়নি")
    return result

API endpoint: POST https://payment.webkoders.com/api/v1/checkout/create/. Header: X-API-KEY. Amount কমপক্ষে 1.00 BDT। Response-এর checkout_url customer-কে দিন; reference_id local order-এ সংরক্ষণ করুন।

ধাপ ৩ — Pay button থেকে redirect করুন

Logged-in customer-এর নিজের order খুঁজুন। উদাহরণের `user`, `payment_status`, `gateway_reference` field আপনার model-এর সঙ্গে মিলিয়ে নিন।

# payments/views.py
from django.contrib import messages
from django.contrib.auth.decorators import login_required
from django.shortcuts import get_object_or_404, redirect
from django.views.decorators.http import require_POST
from shop.models import Order
from .services import GatewayError, create_gateway_checkout

@login_required
@require_POST
def start_payment(request, order_id):
    order = get_object_or_404(Order, pk=order_id, user=request.user)
    if order.payment_status == "PAID":
        return redirect("order-detail", order_id=order.pk)
    try:
        invoice = create_gateway_checkout(order)
    except GatewayError as exc:
        messages.error(request, str(exc))
        return redirect("order-detail", order_id=order.pk)

    order.gateway_reference = invoice["reference_id"]
    order.payment_status = "PENDING"
    order.save(update_fields=["gateway_reference", "payment_status"])
    return redirect(invoice["checkout_url"])

নিজের `urls.py`-এ path("orders/<int:order_id>/pay/", views.start_payment, name="start-payment") যোগ করুন। HTML form-এ method="post" এবং {% templatetag openblock %} csrf_token {% templatetag closeblock %} রাখুন।

ধাপ ৪ — HMAC যাচাই করে webhook নিন

Gateway payment complete হলে আপনার configured Webhook URL-এ payment.completed JSON POST করে। API Secret দিয়ে raw request body-র HMAC-SHA256 যাচাই করুন:

# payments/views.py
import hashlib, hmac, json
from decimal import Decimal, InvalidOperation
from django.conf import settings
from django.db import transaction
from django.http import HttpResponse
from django.views.decorators.csrf import csrf_exempt
from django.views.decorators.http import require_POST
from shop.models import Order

@csrf_exempt  # এই view-তে HMAC signature যাচাই করা হয়
@require_POST
def gateway_webhook(request):
    received = request.headers.get("X-Signature", "")
    expected = hmac.new(
        settings.GATEWAY_API_SECRET.encode("utf-8"),
        request.body,  # raw bytes; JSON parse/re-encode করবেন না
        hashlib.sha256,
    ).hexdigest()
    if not hmac.compare_digest(expected, received):
        return HttpResponse("Invalid signature", status=400)

    try:
        event = json.loads(request.body)
        if event.get("event") != "payment.completed":
            return HttpResponse("Ignored", status=200)
        if event.get("status") != "COMPLETED":
            return HttpResponse("Not completed", status=400)

        with transaction.atomic():
            order = Order.objects.select_for_update().get(pk=event["order_id"])
            if str(order.gateway_reference) != str(event["reference_id"]):
                return HttpResponse("Invoice mismatch", status=400)
            if Decimal(str(order.amount)) != Decimal(str(event["amount"])):
                return HttpResponse("Amount mismatch", status=400)
            if event.get("currency") != "BDT":
                return HttpResponse("Currency mismatch", status=400)

            # Notification একাধিকবার আসতে পারে; paid update idempotent রাখুন।
            if order.payment_status != "PAID":
                order.payment_status = "PAID"
                order.gateway_trx_id = event.get("trx_id", "")
                order.save(update_fields=["payment_status", "gateway_trx_id"])
    except (KeyError, ValueError, TypeError, InvalidOperation, Order.DoesNotExist):
        return HttpResponse("Invalid notification", status=400)
    return HttpResponse("OK", status=200)

উদাহরণে `gateway_reference`, `gateway_trx_id`, `payment_status` field ধরে নেওয়া হয়েছে। আপনার Order model-এ না থাকলে field যোগ করে migration চালান। অন্য customer-এর order update ঠেকাতে local order ownership/reference মিলিয়ে নিন।

`urls.py`-এ webhook route দিন: path("payments/gateway-webhook/", views.gateway_webhook)। `@csrf_exempt` শুধু এই webhook view-তে রাখুন; signature যাচাই ছাড়া paid করবেন না।

ধাপ ৫ — Return page ও live verification

  1. Customer checkout শেষে Return URL-এ ফিরবে। শুধু ফিরে এসেছে বলে paid দেখাবেন না; webhook-এর অপেক্ষায় Pending দেখান।
  2. Webhook না এলে server log ও Super Admin-এর webhook URL/delivery settings পরীক্ষা করুন। Webhook endpoint public HTTPS হতে হবে এবং `200` response দিতে হবে।
  3. Invoice মিলিয়ে দেখতে `GET /api/v1/checkout/<reference_id>/` ব্যবহার করা যায়। শুধু নিজের database-এ সংরক্ষিত reference ID দিয়ে status যাচাই করুন।
  4. Gateway যাচাইয়ের জন্য merchant payment number এবং SMS Forwarder/device setup সক্রিয় থাকতে হবে; checkout link তৈরি হওয়া মানেই payment complete নয়।
Setup সম্পন্ন হলে Merchant Dashboard-এ ফিরে যান এবং API credentials গোপন রাখুন।
